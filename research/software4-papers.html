The plan, and the papers behind it

One model that learns in its own weights. A frozen hybrid cortex, a learnable layer that grows each sleep, and a hippocampus whose links strengthen with use. Text notes and RAG are only baselines it has to beat.

Current plan · what we build

Cortex, learnable layer, hippocampus, sleep

  1. 1 · Cortex

    Frozen hybrid core

    Qwen3.5-2B: 18 Gated DeltaNet layers plus 6 full-attention layers, 262K context, about 12 KiB of KV cache per token. Fallback is dense Qwen3-1.7B.

    HF cards · 2507.06457 · 2510.04800
  2. 2 · Learnable layer

    A new expert each sleep

    A small low-rank expert per deep sleep. Old experts are frozen, so new learning never overwrites them. Rival arm: a sparse memory layer retrofitted into the core.

    Sleep paper · Sparse Memory FT · 2604.05248
  3. 3 · Hippocampus

    Memory that strengthens with use

    A memory graph on an append-only log. HippoRAG 2 plus plastic links: links used together in a verified success get stronger, and unused ones fade. Recall follows strong links first and searches deeper only if needed. Supplies exact recall by day and the replay at night.

    HippoRAG 2 · our ideas
  4. 4 · Sleep

    Replay, dream, check, train

    Select what proved useful or got corrected, and replay it with old episodes. Dream with the Sleep paper's stage. Keep only what passes hidden tests, then train the new expert, distilling from the pre-update model.

    Sleep paper · SEAL · RL's Razor
  5. 5 · Safety gate

    Test what you ship

    Gate the exact quantized model plus experts. Fresh gate items each sleep, canaries, poison checks, auto-rollback. No self-judge.

    1506.02629 · 2507.08794
  6. 6 · Core merge

    The cortex updates, rarely

    Triggered by a metric: the expert cap is reached, forgetting rises, or the backlog grows. It folds the experts into a new core version, at most about weekly, with a full gate and rollback. New bases are rebuilt from the log.

    Our design
Experiment: 9 arms on synthetic streams with hidden tests, 15+ sleeps and 3+ seeds. The baselines are no memory, RAG, long context and a text-notes stack. Then ours with experts, ours with a sparse memory layer, ours without dreaming, a generic-data control, and an oracle. Win means beating the best baseline by at least 3 points, with the CI above 0 and old skills dropping no more than 2 points.

Language Models Need Sleep

use
Google + Cornell · Jun 2026 · 2606.03979

Wake learns fast; sleep adds a new low-rank expert, distils into it from the pre-update model, then dreams self-made practice data rewarded by real gain.

ARC 80 vs SEAL 72.5 · SQuAD 48.9 vs 31.9 base · no dreaming → 35.7

For usTemplate for our sleep loop and learnable layer: a new expert per sleep, distillation, dreaming. Full explainer

SEAL: Self-Adapting LLMs

use
MIT · Jun 2025 · 2506.10943

The model writes its own training notes ("self-edits"), trains a LoRA on them, and is rewarded only if the update improved the score.

SQuAD n=1: 47.0 vs 32.7 · ARC 72.5% vs 0% in-context

For usThe base loop inside the dreaming stage. Its forgetting across edits is why we add frozen experts plus replay.

Sparse Memory Finetuning

use

For usRival learnable layer (arm 6). Memory layers can now be added to an existing model (2604.05248).
