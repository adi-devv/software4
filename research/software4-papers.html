The plan, and the papers behind it

A frozen model works by day. A memory graph and a skill library hold what it learns. At night it reflects, dreams and checks its work. Weights train only when they beat plain text memory.

Current plan · what we build

Day, night, gate

  1. 1 · Cortex

    One frozen base for every arm

    Qwen3.5-2B: 18 Gated DeltaNet layers plus 6 full-attention layers, 262K context, about 12 KiB of KV cache per token. Fallback is dense Qwen3-1.7B. Runs quantized in llama.cpp on the GTX 1650.

    HF model cards · hybrid analyses
  2. 2 · Hippocampus

    Memory graph, never overwritten

    Graph plus vectors, typed and timestamped, with provenance and trust. Append-only: a reconsolidation saves a new version, and revoked content gets a tombstone. Hot/cold tiers. The log is the source of truth.

    HippoRAG 2 · reviews
  3. 3 · Skills

    Lessons as text

    A library of lessons and skills that grows from wins and fixed failures. It is the main way the system learns.

    ACE · ReasoningBank · GEPA
  4. 4 · Sleep loop

    Select, reflect, dream, check

    Pick what proved useful or got corrected. A fixed 8B model reflects. Dreaming follows the Sleep paper's stage (SEAL loop with gradient-based dream picks). Only hidden tests, execution or user corrections can say a dream is good; there's no self-judge.

    Sleep paper · SEAL · 2404.17140 · 2507.08794
  5. 5 · Weights (optional)

    Retrain LoRA from base

    Each deep sleep, retrain the adapter from the base on the full verified log. The frozen base writes the replay answers, with a KL penalty to the base. Kept only if it beats text by at least 3 points with a confidence interval above zero.

    RL's Razor 2509.04259
  6. 6 · Gate + upgrades

    Test what you ship

    Gate the exact quantized model plus adapter, checking for NaNs. Fresh gate items each cycle, a sealed test set for milestones, canaries and poison checks, and auto-rollback. A new base gets rebuilt from the log.

    Thresholdout 1506.02629
Experiment: 8 arms on synthetic streams with hidden tests, 15+ cycles and 3+ seeds. The arms are no memory, RAG, long context, the text stack, text + LoRA, a LoRA control trained on generic data, text + LoRA + self-judge, and an oracle. Step 0: label real failures and benchmark the GTX 1650 before building anything.

Experiments queue

  1. E1

    Sleep-paper consolidation

    A new low-rank expert each cycle, distillation from the pre-update model, and an imitation RL loss. Compared against our "retrain from base". It worked on plain Qwen3-1.7B math (AIME-24 53.2 vs 49.8).

    2606.03979
  2. E2

    Sparse memory finetuning

    11% forgetting vs 71% for LoRA in their setup. Memory layers can be added to an existing model, but the method is built for facts.

  3. E3

    Dense vs hybrid core

    Qwen3-1.7B vs Qwen3.5-2B, with LFM2-1.2B as a third option. Hybrids are cheaper at long context but weaker at exact copying.

    2402.01032
  4. E4

    Hebbian link weights

    Our own bet, off by default. Links strengthen only on verified success, tested against plain HippoRAG 2.

    Our idea
  5. E5

    Our idea
  6. E6 · E7

Memory & continual learning

Language Models Need Sleep

use
Google + Cornell · Jun 2026 · 2606.03979

Wake learns fast; sleep adds a new low-rank expert, distils into it from the pre-update model, then dreams self-made practice data rewarded by real gain.

ARC 80 vs SEAL 72.5 · SQuAD 48.9 vs 31.9 base · no dreaming → 35.7

For usIts dreaming stage is our dream step. Its consolidation (new expert + distillation) is experiment E1. Full explainer

SEAL: Self-Adapting LLMs

use
MIT · Jun 2025 · 2506.10943

The model writes its own training notes ("self-edits"), trains a LoRA on them, and is rewarded only if the update improved the score.

SQuAD n=1: 47.0 vs 32.7 · ARC 72.5% vs 0% in-context

For usThe base loop inside the dreaming stage. Its forgetting across edits is why weights retrain from base with replay.
